## Ara sıra (her 3–4 sürümde bir)
- **A.** Ayarlar → Güvenlik → 📂 Dosyadan yükle → az önce kaydettiğin dosya → Yükle'ye tekrar bas → ilerleme geri gelir. Ayrıca 📤 Paylaş ile yedek Drive'a kaydedilebiliyor.
- **B.** Ayarlar → Hakkında → 📤 Paylaş → WhatsApp seçilebiliyor.
- **C.** Telefonu dik tut → "yan çevir" uyarısı çıkar.
- **D.** İnternet kapalıyken oyun açılır ve oynanır (şu an her şey telefonda).
